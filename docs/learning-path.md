# Learning path

1. Open the [Browser Features app](../public_html/browser-features/).
2. Compare a few capabilities across browsers and distinguish a missing API from an inconclusive probe.
3. Read the [capability reference](capability-reference.md) and [browser support guide](browser-support.md).
4. Explore [WebAssembly](webassembly.md) and [WebMCP](webmcp.md) as examples of newer browser interfaces.
5. Play [たのしい都道府県つみき](../public_html/tsumiki/) to see WebGL2/WebGPU rendering, WASM physics, WebAudio synthesis, and WebCrypto-signed saves combined in one app.
6. Use the [glossary](glossary.md) when browser-security terms are unfamiliar.

The results are observations from the current browser, not a compatibility guarantee for every device or version.
