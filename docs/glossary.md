# Glossary

| Term | Meaning |
| --- | --- |
| Capability | A browser interface or behavior that a runtime probe evaluates |
| `checkRequirements` | Shared guard that verifies app prerequisites before required APIs are used |
| COEP | Cross-Origin-Embedder-Policy; restricts embeddable cross-origin resources |
| COOP | Cross-Origin-Opener-Policy; isolates a browsing context group |
| CSP | Content-Security-Policy; controls resource sources and executable behavior |
| `crossOriginIsolated` | Browser state indicating cross-origin isolation requirements are met |
| SRI | Subresource Integrity; cryptographic digest checked for a fetched resource |
| `untestable` | A probe could not determine support without unsafe assumptions or prompts |
| WebMCP | Experimental browser API for page-registered tools |
| WASM | WebAssembly |
