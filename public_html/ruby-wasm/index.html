    05 · NOTES

    What this proves

    • The 30.6 MB stdlib build ships as an 8.9 MB gzip file and is inflated in-page with DecompressionStream, staying under the Cloudflare Pages 25 MiB file limit.
    • Ruby runs in a dedicated Worker, so an infinite loop never freezes this tab — the Kill button terminates and reboots the VM.
    • JS.global inside a Worker cannot see the DOM, so page toys are reached through a postMessage bridge (Dom/Canvas helpers in prelude.rb). Event handlers registered by Ruby keep working between runs.
    • evalAsync uses Asyncify, so JS::Object#await works on every engine — no JSPI flag needed.
