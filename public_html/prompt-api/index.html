LEARNING MODE

Prompt API is not available in this browser

Live model controls are disabled, but every tab keeps its API examples and requirements visible. The web API is intended for Chrome desktop 148+ on supported hardware; Android and iOS (including all iPhone browsers) are not supported.

  • Windows 10/11, macOS 13+, Linux, or ChromeOS on a Chromebook Plus.
  • At least 22 GB of free storage; GPU with more than 4 GB VRAM, or CPU with 16 GB RAM and 4 cores.
  • Audio input requires a GPU. Initial model downloads need an unmetered connection.
